# Soccer-Prototyp

Spielbarer Test der Ballphysik: [saschahoffmannsh-gif.github.io/soccer](https://saschahoffmannsh-gif.github.io/soccer/)

Der Ball hat Gewicht, rollt mit Reibung aus, klebt nicht am Fuß und dreht sich sichtbar. Drall gibt es nur über einen Bogen-Swipe (am Desktop auch Q/E).

**Touch:** links Stick, rechts tippen = Pass, halten = Schuss laden, wischen = Richtung und Stärke, Bogen = Drall.

**Desktop:** WASD oder Pfeile, Leertaste kurz = Pass, gehalten = Schuss. Q/E beim Schuss für Drall, rechts mit der Maus wischen. `[` / `]` stellen die Ballkontrolle ein, T holt einen Dummy-Gegner, R setzt neu an.
