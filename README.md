# Soccer-Prototyp

Spielbarer Test der Ballphysik: [saschahoffmannsh-gif.github.io/soccer](https://saschahoffmannsh-gif.github.io/soccer/)

Der Ball hat Gewicht, rollt mit Reibung aus und dreht sich sichtbar. Nach einer Annahme klebt er genau 2 Sekunden am Fuß (grüner Ring läuft ab), danach gilt wieder die normale Physik.

**Touch:** links Stick. Rechts drei Knöpfe: **Pass** (kurz, in Laufrichtung), **Schuss** (halten = laden, loslassen = schießen), **Lupfer** (Bogen durch die Luft, tippen genügt, halten = weiter). Frei rechts wischen = Swipe-Schuss, Bogen = Drall.

**Desktop:** WASD oder Pfeile, Leertaste = Pass, Shift/J halten = Schuss, F/L = Lupfer, Q/E = Drall. `[` / `]` stellen die Ballkontrolle ein, T holt einen Dummy-Gegner, R setzt neu an.
